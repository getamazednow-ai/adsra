# ADSRA — Australian Digital Sovereignty Reference Architecture

ADSRA is an open, citable, vendor-neutral reference architecture for digital sovereignty in
Australian enterprises. It answers seven board questions — one per pillar — with control
objectives that engineering teams can build against, indicative AWS / Azure / GCP mappings, a
six-level maturity model, 20 fundable capabilities, and board-level KRIs. Every regulatory claim is
anchored to a primary source in the Technical Reference evidence register (§12).

It is published as a draft **so it can be argued with**. Please break it.

## What is in this repository

| Folder | Contents |
|---|---|
| `docs/` | The v0.3 pack (PDF): Executive Briefing, Technical Reference and White Paper; and a consultation brief for each open question |

The ADSRA article series is published on [Medium](https://medium.com/@duane.gomes).

The Technical Reference is authoritative: control IDs, the indicative AWS / Azure / GCP mappings, the blueprints and the evidence register are all there.

## The five open questions

| | Question |
|---|---|
| **OQ-1** | Tier boundaries — is four sovereignty tiers right, or should Medium split into commercial-sensitive and personal? |
| **OQ-2** | HYOK guidance — hold-your-own-key as a surgical control, or broader? Bring a workload. |
| **OQ-3** | Level 6 governance — what evidence would convince a regulator that agentic remediation is itself well governed? |
| **OQ-4** | Utilities and education — correct or extend the blueprints (Technical Reference §10.5–10.6). |
| **OQ-5** | Cloud mappings — correct the indicative AWS / Azure / GCP mappings against current Australian-region capability. |

## How to contribute

Read [CONTRIBUTING.md](CONTRIBUTING.md), then **open an issue** — there is a form for each open question and one for corrections. Issues are the way in for everything, including the cloud mappings (OQ-5).

Prefer to contribute privately? Use the Contribute section of the Assure Govern website
(Control Packs → ADSRA → Contribute). Private submissions are not published without your consent.

## How this repository is maintained

This is a **published copy**. The master is maintained privately by Getamazednow AI, and each
release is copied here. Accepted contributions are applied to the master through the ADSRA Change
Register and arrive here in the next release. You are told the outcome and credited.
